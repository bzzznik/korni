# KORNI.TLV: сайт и панель управления

Сайт состоит из одной страницы (`index.html`). Весь контент лежит отдельно, в папке `data/` (тексты, цены, товары, контакты) и в папке `media/` (фото). Ребята меняют его сами через **Pages CMS**. Это бесплатная панель в браузере, работает и с телефона. После каждого сохранения сайт обновляется сам примерно за минуту, а загруженные фото автоматически уменьшаются.

```
index.html             сайт (дизайн и эффекты, ребятам трогать не нужно)
data/site.json         о нас, мастера, услуги, контакты, большое фото
data/gallery.json      работы: галерея, след из фото, первое фото
data/products.json     магазин
media/                 все фото
assets/fonts/          шрифт Bravo
.pages.yml             настройка панели Pages CMS
.github/workflows/     автопубликация на GitHub Pages
```

## Разовая настройка (Николай, ~15 минут)

1. **GitHub.** Зарегистрироваться на github.com (если аккаунта ещё нет) → **New repository** → имя `korni` → Public → Create. Затем **Add file → Upload files**, перетащить всё содержимое этой папки и нажать **Commit**.
   Папки `.github` и файл `.pages.yml` скрытые. На Mac их показывает `Cmd+Shift+.` в Finder. Без них не будет ни автопубликации, ни панели.
2. **Публикация.** В репозитории: **Settings → Pages → Source: GitHub Actions**. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/korni/`.
3. **Панель.** Открыть **app.pagescms.org** → **Sign in with GitHub** → установить приложение Pages CMS на репозиторий `korni` → открыть его. Слева появятся разделы «Работы», «Магазин» и «О нас, услуги, контакты».
4. **Доступ для ребят.** В Pages CMS откройте раздел **Collaborators** → добавить их email. Им придёт письмо со ссылкой для входа. Аккаунт на GitHub им не нужен.
5. **Свой домен (по желанию).** Купить `korni.co.il` или `korni.tlv…`, затем в **Settings → Pages → Custom domain** вписать домен и создать в корне файл `CNAME` с этим доменом.

## Инструкция для ребят (можно переслать как есть)

Заходите на **app.pagescms.org** по ссылке из письма и выбирайте сайт KORNI. Слева три раздела:

- **📷 Работы.** «+ Add» → «Фото» → загрузить с телефона → **Save**. Порядок меняется перетаскиванием. Первое фото в списке показывается крупнее всех. Все фото работ также появляются в «следе» за курсором.
- **🛍 Магазин.** Каждый товар: фото, название, описание, бренд, категория, цена и галочка «В наличии». Если товар закончился, снимите галочку: он останется на сайте с пометкой «Нет в наличии». Заказы клиентов приходят в WhatsApp с номером, указанным в контактах.
- **✏️ О нас, услуги, контакты.** Тексты о себе, имена мастеров, услуги с ценой «от», телефон, WhatsApp, адрес, часы работы, большое фото для эффекта «полёт сквозь KORNI».

Русский язык обязателен. Английский и иврит заполнять по желанию: если поле пустое, на сайте покажется русский текст.
После **Save** подождите минуту и обновите сайт.

## Если что-то сломалось
Вся история изменений хранится на GitHub, поэтому любую правку можно откатить: репозиторий → **Commits**.
